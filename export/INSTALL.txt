Vocal DeVerb 0.1.5 - VST3 plug-in for Windows (64-bit)

Install
1. Unzip. You get a folder named VocalDeVerb.vst3 - keep the whole folder together.
2. Copy that folder to:  C:\Program Files\Common Files\VST3
   (Windows will ask for admin permission.)
3. Rescan plug-ins in your DAW, then look for "Vocal DeVerb" (vendor: Local Audio).
   Reaper: Options > Preferences > Plug-ins > VST > Re-scan.
   Adobe Audition: Effects > Audio Plug-in Manager > Scan for Plug-ins.
     Audition only finds VST3 plug-ins in C:\Program Files\Common Files\VST3.
     Don't add the VocalDeVerb.vst3 folder as a custom scan path; custom
     folders are for VST2 only. If it still doesn't show, tick "Rescan
     existing plug-ins" and scan again.

If an older version is installed, close your DAW and replace the old folder first.
